## Scope, Boundaries, and Non-Goals

Preserve F9 normal clipboard, F10 normal insert, Alt+F9 prompt clipboard, Alt+F10 prompt insert, mobile prompt controls/markers, and fixed Luna/maximum prompt cleanup. Standalone and follow-up prompts must not invent missing context.

For reprocessing, use stored `raw_text`, save a linked alternative, preserve the source, and copy only. When raw text is null or blank, disable both actions with an explanation, make no cleanup request, and never fall back to cleaned text.

In the desktop To Do panel, present `pending` as Pending and `actioned` as Archived. Search every archived row locally through bounded keyset paging/Load more. Order by validated `meta_json.mobileInbox.createdAt` descending, fall back to `todo_items.created_at` for legacy/malformed data, then `id` descending; cursors use that tuple. Reset results when a row becomes actioned. Archived items retain cleaned/raw copy and eligible reprocessing but cannot silently return to Pending. Tray count and `Copy newest To Do` remain pending-only.

Correction rules are separate raw-phrase → written-form mappings, applied exactly and boundary-aware before cleanup, with preview/edit/disable/delete. Profiles map manually to the three fixed styles using process identity/name only. Never persist/send titles, screenshots, selections, surrounding text, or clipboard context. Hotkeys stay authoritative.

Flags reference existing records without copied transcript content and use Transcription, Cleanup, Prompt, or Paste/delivery. Use them for local evaluation; retain prompt Luna/maximum unless evidence proves an equivalent.

Label the purge “Delete logs and transcripts older than 30 days.” Capture one UTC cutoff. Database eligibility uses `transcriptions.created_at` and `todo_items.created_at`, never `timestamp` or `actioned_at`. Log eligibility uses the canonical filename’s local calendar date: its whole local day must end before the cutoff; never use mtime for age. Retain data exactly at the cutoff.

Preflight produces an immutable manifest: table/id/`created_at`/content fingerprint for rows and verified root/path/file identity/size/mtime for logs. First confirmation shows its counts, bytes where available, inclusions, exclusions, and permanence; final confirmation defaults to Cancel. Either cancellation changes nothing. Revalidate immediately before execution; any changed/replaced candidate rejects the manifest with no deletion. Never add post-preview candidates.

Purge only canonical EchoDraft desktop JSONL logs (including valid rotated parts, never the active log) and eligible `transcriptions` plus every `todo_items` status. A source row, its transcript-bearing alternatives, and its flags form one deletion unit; preview/result counts must expose each, and transactional deletion must use enforced foreign keys or explicit verified deletes. Exclude audio, mobile data/logs, exports, models, settings, auth, profiles, dictionaries, and correction rules. Never follow links/reparse points, recurse, wildcard, or leave verified roots. Prevent concurrency. Report filesystem/SQLite partial failures, counts, bytes, and residue truthfully; no hidden backup or automatic vacuum.
